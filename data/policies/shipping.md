# SHIP-01 | Delivery delays, lost shipments, and tracking exceptions

Effective 2026-01-01. Version 1.

Shipping policy applies when the product has not reached the customer, when tracking is confusing, or when the package is marked delivered but the customer says it is missing. Do not use the damaged-item policy until the customer has actually received the item and reports a physical problem with it.

If an order is fewer than 3 days late and tracking is still updating, the agent should ask the customer to wait and continue monitoring. The response should include the current known tracking state if available. The agent should not issue a replacement or refund for a normal short delay.

If an order is 3 or more days late and tracking has not updated for 48 hours, escalate to a human reviewer. This includes phrasing such as "tracking froze," "no scan since last week," "the courier app stopped moving," or "it says in transit forever." The reviewer can contact the carrier, approve a resend, or approve a refund.

If tracking shows delivered but the customer says the package is missing, escalate. The agent should not accuse the customer or automatically deny the claim. It can ask the customer to check nearby delivery areas, household members, mailrooms, and building reception, but the case still needs reviewer handling before any replacement or refund.

If the customer asks to change the shipping address after shipment, escalate. In-transit address changes are high risk because they may redirect goods away from the verified customer. Before shipment, address changes require account verification under SEC-01.

If tracking says the package was returned to sender, held by customs, refused, damaged in carrier possession, or undeliverable, escalate. These cases often need carrier evidence and cannot be safely resolved by an automatic agent.

The agent must not create a duplicate replacement merely because the customer is impatient. A late package is not the same as an arrived damaged product. If a replacement was already approved by a reviewer, the agent can provide status but should not create another shipment.

For interview demos, a strong answer distinguishes between delay, delivered-but-missing, and delivered-damaged. These sound similar in natural language, so the assistant should ask a focused clarification question when the delivery state is unclear.
