# RET-01 | Returns, remorse refunds, and unopened items

Effective 2026-01-01. Version 1.

Returns are different from damaged-item claims. A return is when the customer received the correct product and no arrival damage is claimed, but they no longer want it, ordered the wrong item, or changed their mind.

Standard remorse returns are allowed only when the item is unopened, within the configured return window, and not marked final sale, hygiene-restricted, software-activated, or consumable. If the project does not have return-window data, escalate instead of inventing eligibility.

The agent should not route a remorse return through DAM-01 just because the customer wants money back. Damage policy is for arrival damage. Refund policy is for refund status. Return policy is for voluntary returns.

If a customer says "I need a new one" after receiving the wrong color or size, clarify whether the product is damaged, wrong item, or exchange request. Exchanges for preference reasons require return or reviewer handling, not automatic damaged-item replacement.

Return labels should be issued only to verified customers and only to the original delivery country unless a reviewer approves otherwise.
